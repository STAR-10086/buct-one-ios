## 二、M2-1 详细交付范围

1. **北化在线（THEOL · `course.buct.edu.cn`）**
   - 原生 `sidportal` CAS 换取 `/meol` 作用域 `JSESSIONID`，自动处理 GBK/UTF-8 编码与 Tomcat 课程上下文（`enterCourseContext`）。
   - **「作业」Tab（M2-1 点亮）**：两阶段同步在修课程待交作业与在线测验 DDL、本地自定义待办、隐藏/过滤偏好；点击进入原生详情页支持下载附件并调用 `QLPreviewController` 预览，同时提供 Safari 交作业快捷跳转。
   - **「北化在线」工作台模块**：全量在读课程搜索（`blen.student.lesson.list.jsp`）→「课程资源」多级目录与 `download.jsp` 直链下载预览 /「单元学习」目录浏览 /「作业与测验」。
2. **教务消息（`jwNotice` · `jwglxt.buct.edu.cn`）**
   - 原生采集教务个人提醒（调课/补课/停课/考试分类筛选）与教务通知公告，支持关键词检索、分页加载更多、本地已读状态持久化、清洗后安全正文阅读与外链跳转。
3. **i北化（`i.buct.edu.cn` & `mnews.buct.edu.cn`）**
   - 接入 4 栏校内综合资讯（通知公告 / 活动公告 / 招聘信息 / 北化新闻）分页与正文阅读、图书馆在借清单（`getYktOrBook.jsp?type=book`）与应还倒计时颜色标记，并与已有官方校历聚合为统一「i北化」工作台模块。

## 三、开发准入规范与明确不做清单

### 新模块接入自查表
1. **认证**：必须全原生 Swift 网络栈，禁止引入 `WKWebView` 登录流程。
2. **分层**：严格遵守 `BuctModel（零依赖）← BuctStore / BuctNetwork ← BuctSources（子域互不依赖）← BuctSync ← App / WidgetExtension`，合入前必须通过 `check.yml` 静态扫描。
3. **数据层四条铁律**：失败永不覆盖旧 `data`、`never != emptyConfirmed`、改解析器必须递增 `parserVersion`、`capturedAt` 单调不减。
4. **安全与自签红线**：全走 `BuctTlsDelegate` 校方双链校验；Keychain 严禁传入 `kSecAttrAccessGroup`；零第三方商业统计/崩溃 SDK，仅保留可实时关闭的自托管 Umami 零 PII 统计。

### 明确不予接入 / 不做范围
- **北化校园卡小程序（`mcardtoo.buct.edu.cn`）**：强依赖微信 `wx.login()` 绑定与加密通道，存在顶号风险，坚持 `ecard.buct.edu.cn` 原生路线。
- **门户办事大厅（`service.buct.edu.cn`）与低频子系统**（后勤报修 `repair`、财务 `cwmh`、学工 `ixg`、图书馆 OPAC `lib2`）：保持客户端轻量与单人可维护边界。
- **高风险无人值守写操作**：不做自动抢课、代打卡、自动交答案等违规自动化操作，仅提供查询、手动确认与本地通知提醒。
